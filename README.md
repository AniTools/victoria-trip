# Victoria Trip

One-page travel itinerary for a day and a night in Victoria, BC (September 7–8, 2026).

**Live page:** https://anitools.github.io/victoria-trip/

Single self-contained `index.html` — Spanish/English toggle, Day 1 / Day 2 / Map tabs,
per-day routes that open in Google Maps. Open the link on a phone and use
"Add to Home Screen" for an app-like shortcut.
